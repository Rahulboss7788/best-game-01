Mothlight — Keeper of the Last Lantern: an original arcade game. You are the keeper of the last lantern in a twilight garden. Glowmoths drift in from the dark; walk into their glow and they follow your light home, while shadow wisps hunt the keeper and snuff the light. Survive all 5 nights and light the Beacon. Amber moth +10, Azure +25, Crimson +50; combos build to x5; dewdrops mend hearts. No libraries, no build step, no network requests — just static files under game/ that open in desktop Chrome and play, with original art drawn in code and sound synthesised live with the Web Audio API.

## Run it

```sh
python3 -m http.server -d game
```
